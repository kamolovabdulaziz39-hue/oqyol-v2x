# Программно-аппаратный комплекс «Кооперативная система безопасности дорожного движения» (V2X-навигация)
## Интерактивная карта взаимного обнаружения транспортных средств в реальном времени

Кооперативная система V2X (Vehicle-to-Vehicle / Vehicle-to-Infrastructure) разработана для **предотвращения дорожно-транспортных происшествий (ДТП)** на перекрестках, в слепых зонах и при ограниченной видимости за счет обмена телеметрическими данными между участниками движения на ультранизкой задержке (**< 100 мс**).

---

## 1. Архитектура и принципы работы

Система построена по клиент-серверной микросервисной архитектуре, оптимизированной для обработки высокочастотных потоков геоданных (5–10 Hz):

```
+-----------------------------------------------------------------------------------+
|                           КЛИЕНТЫ (ТС / СМАРТФОНЫ / HUD)                          |
|  - HTML5 Leaflet / Canvas темная векторная карта                                   |
|  - Автомобильный проекционный HUD (Windshield Mirror Mode)                         |
|  - Web Audio API (двухтональные предупреждающие и стробирующие сигналы)            |
|  - Web Speech API (голосовые ассистенты на русском языке)                         |
|  - Встроенный тест-драйв (управление стрелками/WASD) и режим реального GPS        |
+------------------------------------------+----------------------------------------+
                                           |  WebSocket (5-10 Hz JSON/Binary)
                                           v
+-----------------------------------------------------------------------------------+
|                             БЭКЕНД СЕРВЕР (FastAPI / ASGI)                         |
|                                                                                   |
|  [ Ingestion Gateway ] -> прием координат, скорости, курса и timestamp (10 Hz)   |
|            |                                                                      |
|  [ Spatial Hash Grid ] -> геоиндексирование O(1), мгновенный поиск соседей 1-3 км |
|            |                                                                      |
|  [ V2X Collision Engine ]:                                                        |
|       * Расчет CPA (Closest Point of Approach) & TTC (Time to Collision)          |
|       * Контроль слепых зон (Blind Spot Detection - BSD, 100°-160° и 200°-260°)   |
|       * Ассистент движения на перекрестках (Intersection Movement Assist - IMA)   |
|       * Динамический расчет рекомендованной крейсерской / безопасной скорости     |
|            |                                                                      |
|  [ Ultra-Low Latency Hub ] -> формирование SafetyUpdate и selective broadcast     |
+-----------------------------------------------------------------------------------+
```

## 2. Физико-математическая модель (TTC, CPA, IMA, BSD)

1. **Точка максимального сближения (CPA) и Время до столкновения (TTC):**
   - Перевод географических координат WGS-84 в локальные касательные декартовы координаты (ENU):
     $$\Delta x = (\text{lon} - \text{lon}_0) \cdot \frac{\pi}{180} \cdot R_{\text{earth}} \cdot \cos(\text{lat}_0)$$
     $$\Delta y = (\text{lat} - \text{lat}_0) \cdot \frac{\pi}{180} \cdot R_{\text{earth}}$$
   - Скорость в м/с и компоненты вектора:
     $$v_x = v \cdot \sin(\theta), \quad v_y = v \cdot \cos(\theta)$$
   - Время максимального сближения:
     $$t_{\text{cpa}} = -\frac{\vec{r} \cdot \vec{v}_{\text{rel}}}{\|\vec{v}_{\text{rel}}\|^2}$$
   - Расстояние в момент максимального сближения:
     $$d_{\text{cpa}} = \|\vec{r} + \vec{v}_{\text{rel}} \cdot t_{\text{cpa}}\|$$

2. **Классификация опасности:**
   - **SAFE (Зеленый индикатор):** $t_{\text{cpa}} \le 0$ (разъезд) или $d_{\text{cpa}} > 35\text{ м}$ или $t_{\text{cpa}} > 6.0\text{ с}$. Разрешена крейсерская скорость.
   - **WARNING (Желтый индикатор):** $t_{\text{cpa}} \le 6.0\text{ с}$, $d_{\text{cpa}} \le 35\text{ м}$, приближение к перекрестку. Рекомендация снизить скорость до 30-40 км/ч. Звуковой сигнал 660-880 Гц.
   - **CRITICAL (Красный индикатор):** $t_{\text{cpa}} \le 3.2\text{ с}$, $d_{\text{cpa}} \le 15\text{ м}$ или опасность в слепой зоне. Экстренное торможение. Стробирующий тревожный сигнал 950-1350 Гц и голосовое оповещение: *"Опасность столкновения! Тормозите!"*.

3. **Пространственный индекс Spatial Hash Grid:**
   - Масштабирование на миллионы пользователей: разбиение карты на ячейки $500 \times 500\text{ м}$.
   - Вставка, обновление и удаление за $O(1)$.
   - Выборка объектов в радиусе взаимного обнаружения (1–3 км) за $O(k)$ без квадратичного перебора.

## 3. Функциональные возможности клиентского интерфейса

- **Периферийный индикатор безопасности:** статусная панель во всю ширину экрана меняет цвет (Зеленый / Пульсирующий желтый / Стробирующий красный), позволяя водителю моментально реагировать боковым зрением.
- **Интерактивная векторная карта:**
  - Собственное ТС с направлением движения (азимут), скоростью и радиусом обнаружения.
  - Соседние ТС с динамическими векторами скорости и прогнозными точками траектории на 5 секунд вперед.
  - Пульсирующий красный луч опасности между конфликтующими автомобилями.
- **Проекционный режим (HUD Windshield Mirror):**
  - Кнопка **🪞 Проекция HUD** зеркально отражает интерфейс по горизонтали для отражения от лобового стекла автомобиля в темное время суток.
- **Режим «Невидимка» (Stealth Mode):**
  - Водитель может отключить передачу собственных координат в эфир, продолжая при этом принимать данные об окружающей обстановке.
- **Акустический и голосовой движок:**
  - Встроенный программный синтезатор звука на Web Audio API (чистые автомобильные зуммеры без необходимости загрузки внешних файлов).
  - Голосовой синтезатор Web Speech API на русском языке.
- **Тарифные планы и подключение:**
  - **Сдать в аренду (1 000 000 сум / месяц):** полный доступ к V2X-радару, предотвращение T-Bone аварий, контроль слепых зон, личный кабинет водителя.
  - **Купить для себя (1 150 $):** пожизненная безлимитная лицензия, персональный локальный сервер, нулевая абонентская плата, интеграция с HUD и регистратором.
- **Личный кабинет водителя (Haydovchi shaxsiy kabineti):**
  - Профиль водителя (ФИО, госномер, марка авто, персональный V2X ID).
  - Счетчики безопасности: безаварийный пробег, предотвращенные аварии, рейтинг безопасности (до 100%).
  - **Отзывы и видеорегистратор:** публикация текстового отзыва с прикреплением видеофайла (видеорегистратор, видео инцидента) и живым видеоплеером.
- **👑 Панель Администратора (Admin Panel — `/admin`):**
  - Единый центр управления платформой для администратора:
  - **Мониторинг всех водителей и их рейтингов:** полный список участников, марка и госномер авто, тарифный план (аренда/покупка), рейтинг безопасности, безаварийный пробег, предотвращенные аварии, возможность редактирования и блокировки.
  - **Управление рекламой:** администратор может размещать рекламу и акции на платформе (заголовок, описание, иконка, ссылка, кнопка), включать/выключать показы в 1 клик, отслеживать показы и клики. Реклама транслируется водителям в реальном времени.
  - **Управление радарами и камерами:** добавление новых радаров, установка скоростных лимитов (50, 60, 70, 80, 100 км/ч), настройка координат и направлений контроля.
  - **Заказы и модерация:** просмотр всех оформленных тарифов и модерация отзывов с видеорегистраторов.
- **📷 Интеллектуальный радар-детектор и умные голосовые оповещения:**
  - База стационарных комплексов фотовидеофиксации («Кордон-М», «Автоураган», «Стрелка-М»).
  - Отображение дорожных знаков ограничения скорости и импульсов сканирования на интерактивной карте.
  - При приближении ТС к радару за 400 метров активируется плавающий **HUD-индикатор радара**.
  - **Умный голосовой AI-ассистент («Осторожно, радар!»):**
    - Если скорость в норме: приятный предупреждающий гонг и фраза: *"Осторожно, радар! Впереди контроль скорости на 60 км/ч. Соблюдайте скоростной режим."* / *"Ehtiyot bo'ling, radar! Oldinda tezlik nazorati. Belgilangan me'yorda harakatlaning."*
    - При превышении допустимой скорости: тревожный строб и экстренное предупреждение: *"Осторожно, радар! Превышение скорости! Ваша скорость {N} км/ч. Срочно сбавьте скорость!"* / *"Ehtiyot bo'ling, radar! Tezlikni oshirdingiz. Zudlik bilan tezlikni tushiring!"*
    - При выезде из зоны фиксации: *"Радар пройден. Безопасной дороги."*
- **Интерактивные сценарии моделирования:**
  1. *Перекресток: слепая зона (T-Bone)* — два ТС сходятся на глухом перекрестке;
  2. *Слепая зона / опасный обгон* — попутный обгон в левой слепой зоне;
  3. *Лобовой риск в повороте* — встречное сближение на закрытом участке дороги;
  4. *Городской трафик (10 ТС)* — распределенный городской поток;
  5. *Ручное управление* — клавиши [↑/W], [↓/S], [←/→/A/D], [Пробел];
  6. *Реальный GPS* — использование физического GPS-приемника смартфона/планшета при установке в авто.

## 4. Запуск и тестирование

### Быстрый запуск (Windows):
1. Запустите файл `run.bat` (или выполните команду `python main.py`).
2. Платформа автоматически запустит сервер и откроется в браузере **Google Chrome** по адресу: **`http://localhost:8085`**.

### Запуск автоматических тестов и бенчмарков:
```bash
python run_tests.py
```

### Результаты бенчмарка производительности:
- Обработка **1000 пакетов** телеметрии (100 одновременных ТС на частоте 10 Hz):
  - **Среднее время обработки пакета:** ~**5.8 мс** (требование ТЗ: < 100–150 мс — запас производительности более чем в 15 раз!).
  - **Пропускная способность одного ядра:** > 170 пакетов/сек в асинхронном режиме.

## 7. Новые функциональные модули платформы OQ YO'L AI

### 7.1. Административная панель (`/admin` и `admin.html`)
- **Управление водителями и рейтингами**: мониторинг всех подключенных водителей, их пробега, рейтинга безопасности (например, 99.2% у лидирующих водителей), предотвращенных аварий и статуса подписки (активен, на 3-дневном бесплатном тест-драйве, заблокирован).
- **Размещение и управление рекламой**: создание рекламных баннеров с настройкой заголовка, категории, эмодзи, ссылки и длительности показа **от 10 секунд до 2 минут (120 секунд)**.
- **Управление дорожными радарами**: добавление, редактирование скоростных ограничений (50, 60, 70, 80, 100 км/ч) и геолокаций камер.

### 7.2. Покрытие всего Узбекистана и Радары контроля скорости
- База радаров охватывает **все 12 вилоятов Узбекистана**, Республику Каракалпакстан (Нукус), Ташкент, а также критические междугородние магистрали:
  - Горный перевал **Камчик (А-373)** (тоннели и серпантины);
  - Международная скоростная трасса **М-39 (Ташкент — Самарканд)**;
  - Самарканд (Регистан), Бухара (Ляби Хауз), Андижан (пр. Бабура), Фергана (ул. Аль-Фергани), Наманган, Карши, Термез, Навои, Джизак, Гулистан, Ургенч.
- **Интеллектуальное речевое оповещение**:
  - При приближении к камере ближе 420 м система анализирует азимут движения и текущую скорость.
  - Если скорость выше лимита: тревожный красный баннер и голосовая команда *"Осторожно, радар! Превышение скорости! Ваша скорость ... Срочно сбавьте скорость!"* (на узбекском и русском языках).
  - При соблюдении скорости: заблаговременное информативное уведомление. После проезда камеры звучит подтверждение: *"Радар пройден"*.

### 7.3. Условия подписки: 3 дня бесплатно и аренда 50 000 сум/месяц
- Прежняя цена аренды (1 000 000 сум/мес) снижена на **95%** — новый тариф составляет **50 000 сум в месяц** (~1 600 сум в день).
- Для каждого нового водителя предоставляется **3 дня бесплатного ознакомительного периода (0 сум)**.
- Доступна также опция вечной покупки пожизненной лицензии за 1 150 $.

### 7.4. Правило дорожной безопасности для рекламы
- **Длительность показа**: настраивается администратором в пределах от **10 секунд до 120 секунд (2 минуты)** с динамическим кольцевым/линейным прогресс-баром и таймером обратного отсчета (`⏱️ 25s`).
- **Блокировка помех водителю (Safety Interlock)**: реклама строго **не отвлекает и не перебивает водителя на дороге**. При движении автомобиля со скоростью более 30 км/ч, в зонах опасности (RED/YELLOW) или вблизи радаров рекламный баннер автоматически сворачивается в компактный полупрозрачный значок без текста и звука. Полный интерактивный вид доступен только при остановке автомобиля (светофор, парковка) в безопасной зоне. Звуковые каналы системы на 100% зарезервированы исключительно для навигации и безопасности дорожного движения.
